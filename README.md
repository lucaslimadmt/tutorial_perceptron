# Tutorial de Perceptron

Notebook acadêmico em Python utilizado para estudar, executar e compreender o funcionamento do Perceptron.

## Conteúdo

O notebook `tutorialperceptron.ipynb` apresenta uma implementação do Perceptron de Rosenblatt e explora conceitos como:

- pesos e bias;
- função degrau;
- taxa de aprendizado;
- treinamento por épocas;
- atualização de pesos a partir do erro;
- classificação de dados linearmente separáveis;
- acompanhamento de erros durante o treinamento.

## Tecnologias

- Python
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

## Como executar

O notebook pode ser aberto em Jupyter Notebook, JupyterLab ou Google Colab.

As principais dependências utilizadas são:

```bash
pip install numpy matplotlib
```
